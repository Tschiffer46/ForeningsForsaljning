## 🎓 Key Concepts Explained Simply

### What is the Repository?
- A folder with all the code and files
- Stored on GitHub.com
- You need to download it to use it

### What is a .md file?
- Just a text file
- Contains guides and documentation  
- Can open with any text editor
- Double-click to open!

### What is localhost?
- Your own computer
- When server runs, it's on YOUR Mac
- Not on GitHub's server
- Not on the cloud
- Right there on your laptop!

### What is Terminal?
- App on your Mac for typing commands
- Press ⌘+Space, type "Terminal", press Enter
- This is where you run the server

### What is npm install?
- Downloads required software libraries
- Like installing app dependencies
- Run once before first use
- Just copy-paste the command

### What is node backend/server.js?
- Starts the web server
- Runs on your Mac
- Keeps running until you stop it (Control+C)
- Creates a database file
- Makes the app work!
