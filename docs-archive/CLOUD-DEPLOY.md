## 📋 Step-by-Step Cloud Deployment

### Step 1: Go to Railway.app (2 minutes)

1. Visit https://railway.app
2. Click **"Login with GitHub"**
3. Authorize Railway to access your repositories
4. **Done!** You're logged in

### Step 2: Deploy Your Repository (1 minute)

1. Click **"New Project"**
2. Click **"Deploy from GitHub repo"**
3. Select **`ForeningsForsaljning`** from your repos
4. Railway starts deploying automatically!

### Step 3: Wait for Deployment (2 minutes)

Railway will:
- ✅ Detect your Node.js app
- ✅ Install dependencies
- ✅ Build your application
- ✅ Start the backend server
- ✅ Generate a public URL

**You'll see:** Build logs showing progress

### Step 4: Get Your URL (30 seconds)

1. Click on your deployed service
2. Go to **"Settings"** tab
3. Scroll to **"Domains"**
4. Click **"Generate Domain"**
5. **Your app URL:** `https://your-app.up.railway.app`

### Step 5: Test It! (1 minute)

1. Open your Railway URL in browser
2. Login with demo credentials:
   - Username: `admin.stockholm`
   - Password: `demo123`
3. **Success!** Your app is live in the cloud!

## 🔧 Troubleshooting

**Problem: Build failed**
- **Solution:** Check build logs in Railway dashboard
- **Common fix:** Make sure all files are pushed to GitHub

**Problem: Can't find my app URL**
- **Solution:** Go to Settings → Domains → Generate Domain

**Problem: App shows error**
- **Solution:** Check deployment logs
- **Common fix:** Wait 2-3 minutes for full deployment
